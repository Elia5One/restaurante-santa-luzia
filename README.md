# 🍲 Restaurante Santa Luzia

Site institucional do **Restaurante Santa Luzia**, especializado em culinária goiana. Desenvolvido com **Bootstrap 5** como projeto de estudo de Autoria Web.

## 📸 Preview

![Preview do restaurante](https://daniellecarneiro.files.wordpress.com/2011/07/dsc_0085.jpg?w=640&h=425)

## ✨ Funcionalidades

- Página inicial com apresentação do restaurante e da culinária goiana
- Carrossel de imagens (almoço, lanches e doces)
- Menu offcanvas responsivo
- Páginas de categorias: Almoço, Lanches e Doces
- Página de cadastro com formulário
- Layout responsivo com Bootstrap 5

## 🛠️ Tecnologias

- HTML5
- [Bootstrap 5.3.1](https://getbootstrap.com/)
